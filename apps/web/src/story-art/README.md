# 首批故事插图

用户指定先制作十课预览。本批选择 C012、C041、C050、C062、C066、C090、C097、C128、C154、C194，覆盖天气、动物、生长、交通、家务、因果、身体边界与节日，不是顺序的前十课。

`images/` 保存内置 image_gen 生成的 1536×1024 PNG 原图；`briefs.json` 保存课文、标题、画面要求与生成提示词。C090 先行样图的实际首次提示词另存于 [首次生成记录](../../../../验收/2026-09-23-故事配图/C090首次生成提示词.txt)，briefs 中是按批次模板归一化的同场景说明。未使用 CLI/API 备用模式。

每张图已逐张查看人物动作、对象与课文关系；分格表达天气变化、种子生长和雨天的两种活动。交通图表现等候，骑车图有头盔与大人检查，身体边界图人物保持距离。生成图片仍适合由家长反馈画风与理解效果，不等于整套课程教学审校完成。

`StoryIllustration.tsx` 仅在 `curriculum-1000-v1` 且实际故事文本匹配时使用对应插图。目录／书架尚未载入完整课文时，以该不可变版本和课号匹配。图文变更或其他版本回退到原有素材，避免把旧插图用于新故事。课程发布包、答案和孩子学习记录未改变。

学习和共读中支持点击放大、关闭或 Escape；书架只放图片，避免按钮嵌套。图片按浏览到的页面加载，首次打开应用不预先下载全部十张。服务工作线程缓存已请求的打包图片，支持 localhost／HTTPS 上已读故事离线查看；局域网 HTTP 的服务工作线程限制沿用原应用行为。

复验：`npx vitest run tests/story-art.test.ts`；在本地部署后运行 `PLAYWRIGHT_BASE_URL=http://localhost:8080 npx playwright test -c playwright.acceptance.config.ts story-art.spec.ts`。截图和图文画廊见 [首批十课验收](../../../../验收/2026-09-23-故事配图/index.html)。
