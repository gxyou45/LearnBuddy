配置在 lessonInteractions.json，按稳定课 ID 与字 ID／文字校验，不依赖目录排序。旧内容版本或目标身份不匹配时保留普通教学页面。生成脚本 scripts/strokes/prepare.py 使用现有前十课及完整课程设计的 C007–C200；保留原十个描写字，其余优先选本课笔画较少的字，同笔画数按课内顺序选择。提交固定配置，运行时不会重新抽选。

## 描笔画

两个字各在自己的 teach 页面显示描写板，不增加课程步骤或必做题量。可演示、抬手续描、刷新恢复，也可直接继续课程。不打分，不计独立识字掌握；原单字音频与继续按钮保留。

只保存笔画序号和当前采样点，不采集原始手写轨迹。记录键继续使用当前账户／孩子（或游客）的 trace:内容版本:课次会话:字ID:v1，两个字独立保存，重玩新会话重新开始。旧十字的轮廓、轨迹与采样算法未改，因此旧 v1 点位继续兼容；仅本浏览器保存，不宣称跨设备恢复描写。损坏存档保留，不覆盖原数据。

408 字均为固定版本 Hanzi Writer Data 的原始记录，附带 public/strokes 中的 JSON、NOTICE 和 Arphic Public License。无外网运行依赖。TraceCharacter 与笔画数据单独懒加载，首页不执行整份笔画数据模块。字形或采样算法以后发生变化时须升级记录键版本。

用户本次已明确授权全部课程的描写扩展与发布。自动化覆盖数据结构、全笔画可达性和界面交互；这些检查不代表新增字形／笔顺、年龄适宜性或安卓真机手感已经人工审校。

## 小兔过河

全部课次 sound／meaning 题共用场景。三字课六步，五字课十步，步数从实际题单推导。首次答对或后续改对前进，错答不倒退，跳过不增加成功；约 500ms 自动继续。最后进入找字阶段显示到岸或休息提示。

进度仍由现有作答及重试派生，不新增数据库字段、独立计数器或学习证据。游客、云端与离线归约逻辑保持现有行为，刷新／补传不重复累加，重玩会话独立。复习和只读重读入口不添加过河或描写。
