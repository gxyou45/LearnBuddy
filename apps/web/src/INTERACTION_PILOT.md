## 描笔画

每课一个目标字：妈、人、来、小、水、鸟、有、山、木、大。在该字的 teach 页面替换展示卡，不新增内容步骤或强制题量；原来的单字音频及继续按钮保留。显示规范轮廓、当前轨迹起点、描写墨迹与短幼苗反馈。手指需从当前位置附近开始，按有限前向窗口推进；不能通过点终点或反向划动直接完成。演示不改变完成状态，减少动效时演示为静态高亮。

只保存笔画序号和当前采样点，不采集原始手写轨迹。记录键为当前账户／孩子（或游客）进度键下的 trace:内容版本:课次会话:字ID:v1，刷新及抬手保留；重玩新会话重新开始，不跨账号复用。当前仅本浏览器保存，不宣称跨设备恢复描写。损坏／无法保存的存档保留，允许继续课程，不覆盖原数据。家长清除游客记录及既有账户／孩子删除清理同时覆盖该命名空间。

素材来自固定版本 Hanzi Writer Data；原始 JSON、来源和 Arphic Public License 随 public/strokes 分发，运行时无外网依赖。strokeData.ts 只是原记录的打包集合，仍按数据许可分发，不将其当作自有字体。字形或采样算法变化时必须升级描写记录键版本，不能直接套用旧点位。审校页：验收/2026-09-29-前十课互动/笔顺审校.html。

## 小兔过河

正式课次 sound／meaning 题共用小兔场景，替换原听音装饰，不新增题目。显示的步数来自本课固定题单中不同题目 ID 的成功答案：首次答对或后续改对算前进，错答和跳过不算；不改变 Attempt、错题和独立掌握规则。答对约 500ms 自动继续，场景移动约 420ms；全部答对时到对岸，下一阶段留下简短完成提示。未全对可直接进入后续阶段，不伪装成全部独立答对。

服务端 sessionDTO 由原有 QuestionPresentation／Attempt／retries 派生 solvedSteps，没有新增数据库字段或写入接口。离线归约器从保存的 presentations 派生同一摘要；CloudProvider 优先读取当前课次的完整离线题单，以兼容未带该字段的旧服务端。游客从当前会话的首次作答及最后改选派生。不新增推进计数器，所以刷新、重试、补传不累加；重玩与复习会话隔离。
