# 完整课程制作与本地发布

课程源稿位于 `课程设计/`。发布保留现有十课及全部素材，追加 C007—C200 共 194 课；原 30 字不重复计数，合计 204 课、1000 字。旧版三个主题保留，新增十个主题分组，因此目录显示 13 个主题分组；设计仍为十阶。

## 制作

1. 将当前正式版本 manifest 保存为 `curriculum-release/base.json`，将其素材复制到 `curriculum-release/files/`。必须使用真实当前基线，不能用旧原型覆盖编辑结果。
2. `python3 课程设计/生成与校验.py` 检查设计源稿。
3. 在 macOS 工作台运行 `python3 scripts/curriculum/build.py`。依赖系统 `say` 的 Tingting 声音，使用本地文件缓存，可重跑；不调用付费语音服务。
4. `node --import tsx scripts/curriculum/verify.ts` 验证全量内容与文件 SHA-256。

`curriculum-release/` 是完整生成包，包含 WAV、原创 SVG 图文卡与找字场景。单字通过例词朗读，使用真实 `audioText`，不把词语录音冒充单字录音；词语／句子的逐字时间为估算。所有素材保留 pending 标记，未声称完成专业人工审校。

已发布的 releaseId 不可复用制作改版。本脚本初始编号为 `curriculum-1000-v1`；后续修订须更新编号并重新读取当前基线。当前生成器用于此次从十课扩充的发布，不支持把已扩充的目录再次追加一遍。

## 发布

先执行 `sh scripts/backup.sh 独立备份路径`，完成构建和测试，再构建镜像 `docker compose build api web`。在工作台执行：

```sh
sh scripts/curriculum/publish-local.sh 已注册且验证的管理员邮箱
```

脚本重新校验内容包、启动已构建镜像、拷贝素材并调用运维发布入口。入口核验管理员、全部文件哈希、旧内容原样保留、当前指针与基线一致；事务创建不可变发布版本并切换指针，写入发布审计。同编号同内容重复执行是幂等的；已存在但已回滚的版本不自动重新启用，须用后台启用。

不修改旧课次、答案、完成记录和离线事件。旧档案只有在新版是严格追加时才自动扩展目录；旧课次继续绑定原问题版本，历史复习使用原问题编号。本机未同步队列先保留，待同步后刷新再扩展。访客本机档案升级前备份为 `:before-curriculum-upgrade`。

如需回退，在 `/admin` 启用发布前版本；已有档案仍保留各自绑定版本，回退当前指针不会删除新内容或学习记录。不要通过覆盖数据库或删除媒体卷回退。

## 验证

- 单元：`npm test`
- 独立数据库：`npm run test:database`
- 完整发布后浏览器：`PLAYWRIGHT_BASE_URL=http://localhost:8080 npm run test:e2e`
- 浏览器 `curriculum.spec.ts` 会检查每一课内容包及故事音频和图片、五字流程、同词干扰项、最终单元和窄屏目录。

本地发布不等于互联网部署。当前没有域名／正式 HTTPS 环境，手机仍需与运行电脑网络互通。
