# DEV-22 复习冷却与间隔

三个复习入口共用以下规则，固定的未完成题单仍原样恢复：

- 已作答的复习字当天休息，答对、答错、提示、跳过均适用；跨题型去重。未作答即退出不消耗候选字。
- 正式课中当天答错或提示过的字，不立即放进课末综合练习。DEV-23 的间隔纠错尚未开发。
- 可信、有效的首次作答按本地日期聚合；独立正确按到期日推进 1／3／7 天，之后保持 7 天。提前正确练习不升级、不推迟原到期日。
- 同日多次正确只算一次；同日任意错误或提示优先，改选正确不抹去原错误。错误／提示回到 1 天；跳过、播放失败、未完整听音及不可信离线时间不升级。
- 调度与掌握标签独立，原规则版本 3 和历史 Attempt 不重写；云端按实际服务端收件时间和孩子时区计算，不采信补传的跨日时间。

没有数据库迁移或素材更新。云端由原始作答推导间隔，并在新有效作答时更新 dueDate；已有 dueDate 不批量改写。游客在现有每字最多 30 条历史内推导，历史不足时保守回退；新增可选 scheduleUsable，旧听音记录不推定为完整播放。游客仍仅本机保存。

这组参数是产品试用启发式，不是经验证的幼儿记忆规律；“仅接触、尚无作答”不会凭空生成题目。真实安卓体验、教学效果和仅接触候选扩展仍待验证／后续开发。
