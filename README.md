# 汉字小屋 · LearnBuddy

面向 **5–6 岁**的亲子识字网页。本地已发布 **1000 个汉字、204 节课**：保留原有十课，追加 194 个五字单元，共 13 个主题分组。每课包含认字、读词、辨音辨义、找字和共读；读完后可进入“综合练习”，融合本课内容、历史错题与到期重点。

## 1000 字完整课程

当前版本：`curriculum-1000-v1`。包含 2000 道辨认题、50 次主题复习、10 次阶段共读检查，以及全量图文共读卡与机器朗读。五字单元可以分两次学习；1000 字是课程覆盖范围，不是统一入学门槛。

[课程设计](课程设计/1000字课程设计.md)与[逐课总表](课程设计/1000字课程总表.md)按 200 个设计单元编排。应用为保护旧进度，把前六个设计单元的 30 字继续保留为原十课，因此实际为 204 课。发布制作流程见 [完整课程发布说明](scripts/curriculum/README.md)。机器语音、估算逐字时间及图文素材仍待专业人工审校。

## 本地开发

已在 Node.js 24.13.1 验证，具体依赖版本由 package-lock.json 固定。

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
npm run build
npm test
npm run test:e2e
```

开发和 E2E 需先运行 Docker 后端与 Mailpit；在 `.env` 的 AUTH_ORIGINS 中加入实际使用的 5173 origin，再重新创建 API。E2E 使用本机 Google Chrome，需要预先运行 5173 服务，不自行启动常驻进程。测试包括十课完整流程、跨章节恢复、找字、故事、清除、存储异常与窄屏布局。网页构建产物为 apps/web/dist/，部署时须同时把 /api 与 /media 代理到后端；当前未部署公网站点。

### GitHub Pages 静态试用版

推送到 `main` 后，`.github/workflows/deploy-pages.yml` 会构建不依赖后端的游客试用版并发布到 GitHub Pages。首次使用时，在仓库的 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**；部署完成后，把 `https://<用户名>.github.io/<仓库名>/` 发给家人朋友即可。

静态版的学习进度只保存在当前浏览器，不包含账户、云端同步或管理端功能。正式版仍使用默认的 `npm run build:web` 构建流程。

当前静态试用版内置前 50 节课（原十课加 C007–C046），约 620 个课程素材，并随包发布已登记的故事插图（目前 112 张，包含用户已产出的 110 张及修订版本）。进入家长入口并选择数字 27，即可从首页任意打开章节。若要继续扩展，先准备本地 `curriculum-release/` 完整课程包，再运行 `npm run prepare:static` 裁剪静态包，最后运行 `npm run build:static`。

工作台托管服务命令（2026-09-21 会话为 learnbuddy-preview，服务 pane 为 %8）：

```sh
WORKBENCH_SESSION=learnbuddy-preview tmux-agent-workbench run --name dev /Users/sophia.gao/Workspace/CodexProj/LearnBuddy -- npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

新环境应按工作台说明先创建相应检查窗口，不直接复用其他项目的 pane。停止时先核实 pane 仍属于此项目。

## 在线学习记录（ACC-02）

登录并选择孩子后，正式课次、继续位置、实际所选答案、提示/跳过及找字结果由服务端保存，服务端判题并生成错题与基础次日复习队列。家长中心可查看错题；辅助完成不计入独立掌握，重读和回顾不移动正式课程位置。只有收到服务端确认才显示“已保存到云端”；响应丢失可重试同一事件，不重复推进。

ACC-03 已支持已缓存课次的离线记录与联网补传，只有服务端确认才显示云端保存。家长中心提供旧记录摘要、目标孩子选择和确认导入，原存档保留；已开始的孩子档案仍绑定原内容版本。完整 1／3／7 天调度与课末综合练习属于后续 DEV-22。实际手机体验待验证。


## 离线同步与导入（ACC-03）

联网开始课次并加载后，可在断网时继续当前已缓存课次。页面显示待同步数量；联网后自动补传，刷新不会更换事件编号。新课次需要联网，多设备发生冲突会保留本机副本，由家长选择继续云端位置。退出账户后队列仍归原账号，登录其他家庭不会上传到新孩子。

旧记录导入入口：家长中心 →“本机旧记录已保留 · 导入记录”→ 选来源与孩子 → 查看摘要 → 确认。重复导入不多记，已有云端位置优先；旧布尔对错不算新独立掌握。

当前手机局域网 HTTP 地址支持已打开页面离线继续；完全断网刷新或重新打开应用需 HTTPS/localhost 的应用外壳缓存。不要清理尚有待同步记录的站点存储。数据边界、同步协议与部署限制见[账户与学习数据设计](./账户与学习数据设计.md)和[部署与维护](./部署与维护.md)。

## 数据导出与删除（R7 本地版）

打开 `/#account` →「导出与删除数据」，选择整个账户或某个孩子。导出 JSON 包含云端学习记录及当前设备的待同步/冲突副本；不含密码、登录令牌，其他设备尚未上传的数据不在其中。

删除需要输入完整邮箱或孩子昵称，并验证当前账户密码。删除孩子保留其他孩子；删除账户会退出所有设备。已使用新版的其他设备联网并重新读取账户时清理相应缓存与队列，旧补传不会重建档案。游客记录独立保留；下载的导出文件需自行管理。

本轮按用户确认仅做本地开发与验证。正式域名、HTTPS、真实邮件及安卓双设备验收尚未具备条件，不能据此标记公网试用完成。备份恢复必须同时重放最新删除凭据，详见[部署与维护](./部署与维护.md)。
